### 优化轮（按反馈调整）

前两轮针对《同频》的调整（素材 `art/q1_*.png`，逐帧比对见 `art/refine_compare.png`）：
肖像改为暖金主光 + 冷青补光、主角移到画面右侧，字标不再压脸；数据墙去掉头顶光环，
改成左上落下的暖金光束；眼中数据流减少横穿画面的杂线。

**第三轮（最新，素材 `art/q3_*.png`）**——按"眼睛镜太突兀"和"人物太漫画抽象、缺细节、
背景不丰富"两条反馈重做：

* **眼中数据流**（`q3_eye`）：代码**不再是一层层贴上去的发光方块**，而是压到画面暗部、
  与睫毛/发丝遮挡关系一致，亮度跟着眼角阴影走；只留少量细字符从下缘与右上角透出，
  去掉横贯瞳孔的亮带，瞳孔高光仍由单一主光决定 —— 数据"在场景里"而不是"浮在脸上"。
* **数据墙**（`q3_hall_b`）与**数据教堂**（`q3_hall`）：角色重做为**半写实高细节**——
  发丝逐根透光、蕾丝裙边/荷叶边/鲸鱼刺绣、衣褶与皮肤反光都保留；背景分三层纵深
  （前景悬空面板 → 中景机柜阵列与拱肋 → 远处光井），地面湿黑玻璃带长条金色反射。
  开场用 `q3_hall` 广角推近，中段 `q3_hall_b` 中景（人站在弯曲控制台数据墙前），
  收尾再回到 `q3_hall` 拉出，人物全程抬头不入画框、不被字标遮挡。

镜头顺序（8.00s）：数据教堂广角推近 → 数据墙中景（暖金光束）→ 触碰面板 → 肖像 →
眼中数据流（闪光切）→ 拉回数据教堂收尾 + 字标。

### 品牌标：蓝鲸 + DeepSeek

字标下加回了原片的品牌元素——**DeepSeek 蓝鲸图标**，和 `DeepSeek` 字形组成一个左图右字的
lockup（原片四段只有字形，没有图标；图标形状取自官方品牌图形，见 `art/whale_ref.png`）。

* `art/whale_mask.png` 是从品牌图形里提出来的**形状掩膜**：按色彩饱和度取形，腹部月牙白与
  眼圈两个镂空都保留，边缘无灰晕；再 4× 放大后叠加，曲线不糊。
* 上色不用固定色：脚本把**字标自身逐行的平均颜色**取成一条渐变，套在蓝鲸上，所以图标与
  `DeepSeek` 字形永远是同一种材质、同一种明暗（《同频》青蓝金属、《升维》紫罗兰金属），
  底边与字形基线对齐、左侧留 30px 间距，背面同款暗色剪影光晕。
* 出场时间和字标一致：随 `progress` 淡入 + 轻微上浮。

## 做法（`scripts/make-original-intro.py`）

```
media/original/art/*.png        以原片 1080p 帧作参考图生成（1376×768 或 1365×768）
  → media/original/sr/*_x4.png   Real-ESRGAN realesr-general-x4v3 放大 4×（镜头推进才不糊）
  → 2560×1440 画布上按镜头插值裁切（推/拉/横移，smoothstep 缓动）
  → 叠化 0.30s + 切点闪光 + 粒子（按各段配色着色）+ 数据流字符 + 阈值泛光
     + 暗角 + 胶片颗粒（±3 级）+ 渐变遮罩
  → UI/字标图层（淡入 + 打字机 + 进度条）
  → 无损 libx264rgb 母版 → 2K / 1080p 交付编码
```

单帧合成约 1.2 s（2 核），整段 8s ≈ 5 分钟；音频用 numpy 直接合成。

复现：

```bash
# 素材（可选，仓库里已含），再放大 + 渲染
python3 scripts/make-original-intro.py --clip resonance --work /tmp/orig --crf 15
python3 scripts/make-original-intro.py --clip ascension --work /tmp/orig --crf 15
```

## 手法边界（重要，先说清楚）

成片是**静帧画面 + 电影级运动**：推拉摇移、叠化/闪光转场、粒子/光晕/颗粒、UI 与字标浮现。
**做不到**角色连续表演、口型、镜头内大变形的动画 —— 这里没有视频生成模型可用。
因此镜头靠"多镜头剪辑 + 运镜 + 转场"来讲节奏，和原片那种连续运镜的观感会有差别。

## 修正记录（对比评测时发现）

* **2K 档色彩矩阵**：与母版同尺寸时 `format=yuv420p` 会走 swscale 的 bt601 默认系数，而文件标 bt709
  （实测 ΔY 3.31 级）。已改为显式 `scale=...:out_color_matrix=bt709:out_range=tv`，复测 ΔY −0.22 级，
  两档 1080p↔2K 一致性 43.9–44.6 dB。
* **渲染可复现**：分镜数据流的随机种子原为 Python `hash()`（逐进程随机），两次渲染结果不同。
  改为 `zlib.crc32` 后两次试渲染的成片逐字节一致。
