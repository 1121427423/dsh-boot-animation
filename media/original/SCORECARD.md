口径说明：老片 ΔYUV 偏大是**源片没有色彩标签**（源按 601 解释、交付显式 709）造成的约定差异，不是超分损失；
新片与自己的无损母版同矩阵，所以 ΔYUV ≤ 0.22 级。老片 PSNR 是 manifest 里的**末帧**口径，新片同一口径再给中位/均值。

## 3. 结论

* **技术分两代基本持平（96–97/100）**，但强项不同：老片赢在"内容不变"（对源逐帧一致、音频逐位相同），
  新片赢在"自己的镜头更干净"（时域噪声比 ~1.00×、ΔYUV ≤ 0.22 级、双档一致）。
* **不可比的项**：老片是同一内容的超分重建，"对源相似度"是它的核心指标；新片是原创画面，没有"源"，
  该项换成"对无损母版的编码忠实度"。
* **新片两个已知取舍**：① 音轨比老片响约 6–9 dB（−19.7 vs −26.1 dBFS），峰值 −2.6 dBFS 仍有 2.6 dB 余量；
  ② 调色板按你的放权刻意跳出老片的青蓝族（距离 0.57 / 0.88），若要贴回老片配色只需改一段调色板重渲。

## 4. 本轮对比中修掉的两个真实缺陷

1. **2K 档色彩矩阵**：母版是全范围 RGB，2K 档与母版同尺寸，编码时 `format=yuv420p` 走了 swscale 的
   bt601 默认系数，文件却标 bt709（实测 ΔY 3.31 级、ΔU −1.72 级）。已改为显式
   `scale=...:out_color_matrix=bt709:out_range=tv`，复测 ΔY −0.22 级。
2. **渲染不可复现**：分镜数据流用了 Python `hash()`（每个进程随机），同一命令两次渲染成片不同。
   已改为 `zlib.crc32`；两次 12 帧试渲染的成片 md5 完全一致。
